# 听力场景词汇 · 记忆助手

雅思听力场景词汇记忆页面：24 个场景、1410 条词条、1373 个不重复词条，全部带英式（RP）音标。

## 文件

- `index.html` —— 手机版（移动优先布局：底部四个标签，词表 / 卡片 / 听写 / 测试）
- `desktop.html` —— 电脑版（词表 / 记忆卡片 / 听写 / 选择测试，带侧边章节导航）

## 功能

- 词表：搜索、按场景筛选、只看未掌握、点词条即朗读、一键标记掌握
- 记忆卡片：点卡片翻面、左右滑动换词、认识 / 不认识
- 听写：听发音写单词，回车判对错
- 选择测试：中英双向四选一，统计得分与连对
- 掌握进度保存在浏览器本地
- 发音优先使用系统语音合成（离线可用）；没有英语语音时在页面内直接播放在线音频（不跳转、不显示单词）

## 每行的音标都经过人工核对，原文中的 OCR 错字（如 Ba1Cony、鳖鱼、麻风病、地幔等）已修正。
